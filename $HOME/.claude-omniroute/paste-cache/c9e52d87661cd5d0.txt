3. RECEIPT NUMBERING
============================================================

Payment receipts require server-generated receipt numbers.

Receipt numbers must be:

- generated on the backend
- unique
- concurrency-safe
- tenant-aware where appropriate
- never generated by the frontend
- never based solely on frontend timestamps
- protected against duplicate numbers

Use PostgreSQL-safe concurrency mechanisms.

If a new database model is required, create it properly.

Do not create receipt numbers using an unsafe:

MAX(receipt_number) + 1

pattern without concurrency protection.
